# FOC-060 TDD evidence

## Source plan

The user journey and acceptance criteria came from the FOC-060 task plan in
Focus Queue's task support directory.

## User journeys

- As a task owner, I want agent report stages to update task status, so the
  queue reflects active work without manual edits.
- As a task owner, I want Backlog to remain the default and QA-stage work to
  use the existing QA status, so the queue has no redundant status choice.
- As an agent, I want a generic In progress fallback, so an unavailable precise
  stage does not leave the task looking untouched.
